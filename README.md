# AI-powered Drug Detection NLP Framework with Knowledge Graphs

An AI-powered system that reads handwritten prescriptions using OCR, extracts drug names using BioBERT NLP, and detects dangerous drug interactions using a Knowledge Graph.

## Install
pip install networkx matplotlib pandas requests tqdm transformers torch torchvision Pillow sentencepiece datasets seqeval

## Run
python pipeline.py

## Results
BioBERT fused model: 80% accuracy
